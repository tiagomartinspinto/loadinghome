# Auto da Espera

`Auto da Espera` is a fictional black-and-white administrative browser artwork about residence, waiting, recognition, and procedural visibility. The work presents a case interface in which a person can be recorded, verified, economically legible, and physically present, while the decision that would confirm belonging remains withheld.

The interface is not a real immigration form and does not copy official Finnish government branding, wording, or visual identity. It uses the language of records, categories, requirements, and incomplete status to place the viewer inside an administrative condition rather than explain that condition from the outside.

The work contains no analytics, cookies, uploads, external API calls, or data submission. Interaction changes the case state but never resolves it. In exhibition mode, the system slowly cycles through pending categories, requirements, and verification residues while retaining non-resolution.
